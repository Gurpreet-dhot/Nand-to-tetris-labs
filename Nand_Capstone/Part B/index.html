Answer: Open Box.asm. At label (START_DRAW), locate the starting address line (e.g. @17280). In Hack architecture, each screen row has 32 words. To move down by 10 rows, add 320 (32 × 10): change @17280 to @17600. Save, re-run python assembler.py Box.asm, and reload in CPU Emulator!
Q1: How is the Screen memory mapped in the Hack computer?
Answer: Hack has a 512×256 monochrome screen. Each row consists of 512 pixels = 32 words of 16-bit (32 × 16 = 512). The screen memory starts at RAM address 16384 (0x4000) and ends at 24575. Row r starts at address 16384 + (32 × r).
Q2: How does your program detect keyboard press?
Answer: RAM address 24576 (@KBD) maps to the physical keyboard. When no key is pressed, RAM[KBD] = 0. When any key is pressed, it contains its 16-bit ASCII scan code (non-zero). The code reads @KBD; D=M; and jumps to KEY_PRESSED if D != 0.
Q3: How does your Python assembler handle the two passes?
Answer: Pass 1: Strips whitespace and comments, identifies label declarations like (LOOP), and records the current ROM instruction index in the symbol table (and checks for duplicates for K mod 3 == 2). Pass 2: Translates A-instructions and C-instructions into 16-bit binary, allocating RAM addresses starting at 16 for any newly encountered variable symbols.
Q4: Why does writing -1 make pixels black and 0 make them white?
Answer: In two's complement 16-bit representation, -1 corresponds to 0xFFFF (all 16 bits set to 1). Each 1 bit turns on one black pixel on the monochrome display. 0 clears all 16 bits to 0 (white).

🏛️ Hack Computer Architecture (Part A)

The Hack platform is a Von Neumann architecture machine comprising:

  • CPU.hdl: Contains ALU, A-Register, D-Register, and Program Counter (PC). Decodes 16-bit A- and C-instructions, performs arithmetic/logic, and computes branch targets.
  • Memory.hdl: Full address space multiplexing:
    • 0x0000 - 0x3FFF (0 - 16383): Data RAM (16K words)
    • 0x4000 - 0x5FFF (16384 - 24575): Screen Memory Map (8K words)
    • 0x6000 (24576): Keyboard Input Register (1 word)
  • Computer.hdl: Top-level chip joining ROM32K, CPU, and Memory with system reset.
